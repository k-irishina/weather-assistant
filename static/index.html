What does this do?

This page provides you with a compact and efficient forecast for the chosen location.

You no longer need to dig into the hourly forecast - this provides you with all the info you actually care about.

Average temp, rain, sun, wind and UV index for the day. Simple and easy.

If you turn on notifications, you will get push notifications for the chosen location:

  • Morning forecast — every day at 07:15
  • Sunshine update — at 12:15 if the sun outlook for the day has changed - so you can use it as you should 🌞

*Times are GMT+2.


For more locations and/or any questions, contact the person who gave you the link :-P
