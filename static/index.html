What does this do?

wAsst. provides you with a compact and efficient forecast for the chosen location.

You no longer need to dig into other hourly forecasts - wASS provides you with all the info you actually care about.

If you turn on notifications, you will get push notifications for the chosen location:

  • Morning forecast — every day, with average temps, rain, sun & wind warnings.
  • Sunshine update — at 12:15 if the sun outlook for the day has changed - so you can use it as you should 🌞
  • Rain updates — you will be notified if your morning forecast did not indicate rain or if strong rain is incoming.

Times are GMT+2.

Please send your feedback or feature requests! You can also create an issue on GitHub.
